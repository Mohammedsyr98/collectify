# @collectify/design-tokens

Shared visual decisions for Collectify.

This package is the source of truth for cross-platform design tokens. Web and
future mobile UI implementations should consume these tokens, but should keep
their components platform-specific.

## Imports

```ts
import { tokens } from '@collectify/design-tokens';
```

```css
@import '@collectify/design-tokens/css';
@import '@collectify/design-tokens/tailwind.css';
```
